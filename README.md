# 软件工程第四小组 · Group 04 Studio

徐敬轩、文敬雄的小组成员主页，整合原仓库的数学练习、24 点、骰子游戏与 PersonalCodeStudio 的主页设计、多语言代码统计和网址导入。

## 快速运行

需要 Python 3.10 或更高版本。Windows 双击 `start.bat`，等待依赖安装，然后访问 **http://127.0.0.1:5050**，保持窗口打开。按 Ctrl+C 停止服务。

在 PyCharm 中打开本仓库，解释器选择 `.venv/Scripts/python.exe`，运行 `app.py` 或 `main.py`。两者启动同一个融合后的应用。

手动运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

macOS / Linux：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

端口占用时先设置 `PORT` 环境变量。服务默认仅本机访问；发布到互联网时需要另外配置正式 WSGI 服务、固定 `SECRET_KEY`、HTTPS 与访问控制。上传 GitHub 仓库不会自动部署网站。

## 博物馆展播

从小组首页或项目页进入「博物馆多媒体播放器」。本地播放无需后台密码。需要启用集中管理时，先在 PowerShell 中为本次启动设置展播密码：

```powershell
$env:MUSEUM_ADMIN_PASSWORD = '请替换为你自己的密码'
.\.venv\Scripts\python.exe app.py
```

点击播放器右上角「展播管理」，使用账号 `admin` 和上面设置的密码登录。该密码独立于 `STUDIO_ADMIN_TOKEN`。未设置时，后台禁用。

1. 在「素材库」上传图文或视频。可改名、分类，设置图片和文本的停留时长，添加普通字幕、文字水印；视频也支持粘贴 WebVTT 文本。
2. 在「终端」为屏幕设置编号、名称、分组。同组使用相同组名；打开后台生成的终端链接后可进入全屏。
3. 在「播放计划」选择目标和播放日期、时段，支持持续、一次性、每日和每周。每个计划可选单区、左右双区或四区网格，各区域独立循环图片、视频及文本。
4. 在「滚动字幕」设置广告或通知的内容和发布时间，可发送给全部终端、一个分组或一块屏幕。在线终端约每 3 秒获取更新。

### PDF、PPT 和 Word 文档导入

播放器首页点击「导入本地素材」，可直接选择 `.pdf`、`.docx`、`.doc`、`.pptx`、`.ppt`。本机浏览器导入无需启用管理后台。图片视频在浏览器中读取；上述文档会上传到本机网站，转换为逐页图片并加入播放清单。设置每页停留秒数、开启「自动播放下一项」和「循环整个清单」即可混播并循环。管理后台的素材库也支持这些格式。

首次运行或更新后，请重新运行 `start.bat` 安装 requirements.txt 中新增的 `pypdfium2` 和 Pillow，再重启网站。PDF 不需要 Office 或 Poppler；DOC/DOCX 转换仍需要服务器电脑安装 Microsoft Word；PPT/PPTX 需要 PowerPoint。终端浏览器无需安装 Office。最多 50 MB、100 页；损坏或加密文档会提示失败，不会加入素材库。

远程终端在首页导入文档需先登录展播后台；本机导入接口只对回环地址免登录，写入请求需由本页发起。转换后的页面保存在 museum/data，原文档仅管理员可下载。刷新播放器后需重新导入本地清单；若要跨刷新保留播放安排，请使用管理后台的计划功能。

文档按静态页面播放；不播放 PPT 动画、切换特效或嵌入音视频。请使用可信的未加密文档。

排期以服务器的本地时间为准；重叠计划先比较优先级，同优先级下单终端优先于分组和全部。图片与文本到时切换，视频播完切换。多个屏幕可播放同一内容，各自起播，未提供帧级同步。

素材和配置保存在 `museum/data/`（可通过 `MUSEUM_DATA_DIR` 改址），不会提交 GitHub。默认仅本机访问；同一可信局域网演示时，可在服务器上设置 `$env:STUDIO_HOST = '0.0.0.0'` 后重启，终端链接改用服务器局域网 IP。播放链接和素材无需登录，部署时使用非敏感素材；互联网发布需要 HTTPS 和访问控制。目录存储适合单进程运行，勿让多个服务进程同时写入同一目录。

## 代码统计与网址导入

- 单文件、上传合计、网址下载及解压后总量均限制为 **1 GB = 1024³ 字节**，最多 10,000 个文件；请求额外预留 4 MB 表单开销。忽略 Git、虚拟环境、node_modules 等目录。
- 使用 Pygments 识别多种语言，统计物理总行数、代码行、纯注释行、空行和含注释行。代码与行尾注释同行时计为代码行，同时计入含注释行；Python 文档字符串与 C/C++ 预处理指令计为代码。
- 语言汇总表按课程图片提供：语言、源文件数、代码行数、空行数、注释行数、函数个数、最大值、最小值、均值、中位数。固定显示 C、C++、Java、Python、C#，其他语言有文件时追加行。
- 后四项按**每个函数的有效代码行数**计算，包含定义行、Python 装饰器和有内容的括号行，不含空行与纯注释行。Python 用 AST，C/C++/Java/C# 用 Tree-sitter 识别带函数体的定义；计入类方法、构造函数与 C# 局部函数，不计单独声明、调用和匿名 lambda。嵌套函数分别计数，外层长度包含嵌套部分。跨文件合并全部函数长度后再计算均值和中位数，不平均文件均值。
- 没有函数时函数数为 0、长度指标为“—”；未支持函数分析的语言保留行数统计，函数列为“—”。语法不完整会列出文件，并用 * 标记可能不完整的汇总；不把解析失败伪装成准确的零函数。CSV 同时包含语言汇总表和文件明细。
- 网址支持公开 GitHub 仓库首页、单文件 blob 链接、源码直链和 ZIP。普通网页仅取得返回的 HTML，不能取得服务器后端代码；暂不支持需要登录、验证码的地址与 GitHub 子目录。
- 仅连接公开互联网地址的标准 HTTP/HTTPS 端口，逐次校验重定向并固定已验证 IP；不读取本机或内网地址。下载写入临时文件，处理后关闭，不执行上传源码。
- 保留准确词法分析需要内存中的完整解码文本，接近 1 GB 的单文件可能需要数 GB 内存并耗时较长。已验证大小配置、边界及超过旧 24 MB 限制的真实上传，未做完整 1 GB 单文件性能测试。

## 可选 OCR 与题库

Windows 10/11 支持系统自带 OCR 回退：未安装 PaddleOCR 或推理失败时，使用系统已安装的 OCR 语言在本机识别。系统回退引擎无法可靠区分同一行的多道题时会提示裁剪成单列或安装 PaddleOCR，不会直接把这些题合并成一道。

OCR 支持识别整页多道四则运算题，兼容 PaddleOCR 2.x 和 3.x。先展示识别到的题目数量，再生成逐题答案框；确认算式和题数后填写并统一批改。可修改误识别算式、删除多余项和补录漏题；同一页的相同算式分别保留。识别数量不保证等于原图题数，请人工核对。识别依赖与基础运行环境分开安装。推荐为 OCR 创建 Python 3.11/3.12 环境，再执行 `python -m pip install -r requirements-ocr.txt`，并用该环境运行 `app.py`。首次识别可能下载模型，需要网络连接；非 Windows 系统仅安装基础 requirements.txt 不会启用 OCR。页面会显示依赖缺失、引擎失败或未找到有效算式的具体提示。

基础功能只依赖 `requirements.txt`。图片识别沿用原仓库的 PaddleOCR 适配；未安装兼容的 PaddleOCR/PaddlePaddle 时，Windows 尝试系统 OCR；其他系统会提示识别不可用，其他功能正常。不同 Python 版本的 OCR 包兼容性不同，不作为默认依赖。

不在每次启动时生成一万题，避免启动等待；普通练习会按需补题。数学批改每次最多提交 200 题，算式最多 512 字符、答案最多 128 字符；指数限定为 -12 到 12 的整数，并限制运算数位数和中间结果大小。

普通练习和打印出题使用约 2 秒的时间预算；可生成题目不足或达到预算时返回已生成的题目，实际题数可能少于请求数量。

## 语音出题

从数学工具页或项目列表进入 `/math/voice`。点击“开始说题”，允许麦克风，说“第一题三加五，第二题十二减六”，再点击“停止录音”。页面保留识别文字，转换为两道算式并生成答案框；核对算式后填答案、统一提交。结果写入当前浏览器会话的练习记录，来源为 voice。

语音由浏览器 SpeechRecognition 服务转写，通常需要联网，音频可能发送给浏览器服务商。应在 localhost 或 HTTPS 下访问；不支持的浏览器会提示并允许直接输入文字。本版本支持整数四则运算和括号，未识别出的片段单独列出供修改。浏览器测试模拟了识别结果事件，已验证生成题目与批改，但未对真实麦克风录音测量识别准确率。

## 错题练习与学习分析

数学题提交后，打开“错题与学习分析”查看当前浏览器会话的报告。普通出题、图片识别、语音出题和错题练习共用答题记录。报告统计最近 10000 条记录，排除无法解析的算式，并按题型的答错次数、错误率排列重点练习建议。少于 5 题标注样本较少。错题最近一次答对即标记为已订正；可以切换查看已订正题目。

点击专项练习后，先安排原题，再生成保持运算结构和题型的变式；题目数支持 5、10、20，生成不足时按实际数量展示。提交后自动更新报告，支持下载文字报告和浏览器打印。会话身份保存在浏览器 Cookie；本地运行的密钥保存在 instance/session.key，重启后继续使用。清除 Cookie、更换浏览器或更换密钥后不会自动关联旧记录。运行目录 instance/ 和数据库文件不应上传仓库。

## 代码版本对比

分别选择旧、新版本文件、文件夹或 ZIP，合计上传大小不超过 1 GB。默认忽略各版本共同的最外层目录，适配 GitHub ZIP 的版本目录名；需要完整路径匹配时取消勾选。比较沿用代码统计的语言识别、忽略目录和跳过规则，显示所有跳过项及函数解析提示。

按解码后的源码 SHA-256 判断内容变化，统一换行和文本编码，其他空白变化仍记为修改。同名文件即使行数不变也能识别修改；不同路径的文件按新增、删除展示，不自动推断重命名。行数变化是两个版本的统计净差，不是逐行 diff；函数不受支持或解析不完整时不显示确定的函数增减数。可下载 JSON 对比报告。源码只在本地请求期间处理，不保存上传文件。

## 练习续接、自适应难度和趋势报告

普通数学练习、错题专项、语音题和图片题分别保存一份未提交草稿。题目、已填答案和相关设置保存在浏览器 localStorage，输入时即保存；关闭程序或浏览器后，使用同一浏览器、同一网站地址（包括端口）重新打开，点击“继续上次练习”恢复。开始新练习会覆盖该模式的旧草稿；提交成功后清除草稿。图片题恢复算式和答案，不保留原图；语音题保留已生成算式及对应识别文字，不保留音频。清除网站数据、无痕模式或禁用浏览器存储会影响草稿保存，页面会显示保存失败提示。

数学练习页面可开启“自适应难度”，保留题数设置，由系统决定数值规模和运算结构。支持加法、减法、乘法、除法、混合、括号、负数、分数和乘方，难度为 1 至 4 级。各题型独立调整：在最近 1000 条记录中取最近 20 次同类有效作答，已有自适应记录时只参考当前难度记录；至少 5 题后，正确率达到 85% 升一级，低于 60% 降一级，其余保持。首次使用参考同类历史，无记录从 1 级开始。综合推荐优先选择最近 100 次有效作答中答错较多的题型；没有错题时沿用最近练习的题型。只打开页面或请求出题不产生作答记录，也不会连续升级。每组题展示难度、样本数量和调整原因；更换题型后重新计算。

学习分析新增近 14 天答对 / 答错题量图和每日明细，以及近 7 天与之前 7 天的正确率、练习量、活跃天数和期内错题订正率。没有作答的日期正确率为“—”，不作为 0%；无法解析的算式、异常日期和未来日期不计入趋势。期内错题订正率按本期曾答错、且本期最近一次答对的不同算式计算，不表示长期掌握。趋势沿用报告最近 10000 条记录的范围，超过时提示截断。样本少于 5 次时提示样本不足，正确率变化也受题型和难度变化影响。下载的文字报告和打印报告包含趋势数据。

已提交答题记录保存在 SQLite，浏览器身份 Cookie 当前会保留 31 天（访问后续期），本地密钥保存在 instance/session.key；同一浏览器重开和程序重启后可继续关联记录。草稿不依赖身份 Cookie，但仍限定同一个浏览器的网站地址；更换浏览器或清除身份 Cookie 后，旧答题记录不会自动关联。
